Zoommap

Darstellung der kompletten Map in einem eigenen Fenster mit zoomfähigen Koordinatengitter zur genauen Positionsbestimmung von Basen und Schiffsgruppen.
Der Ausschnitt kann mit der linken Maustaste verschoben werden und mit dem Scrollrad vergrößert/verkleinert werden.
Wenn Schiffe schießen wird das durch einen roten Pfeil angezeigt. Der Pfeil ist blau wenn Schiffe der eigenen Allianz schießen.

Cont. update

The time (in milliseconds) how often the zoom window is synchronized with the browser. Default value is 666. Allowed values: 50...999.
Your sweet spot value can be saved for the future. Type 0 and save it if you want to go back to the dafault value.

Basenstärke

Zeigt die Basen in der Map mit einem Geschützstärke-Indikator an. Je dunkler, desto stärker die Geschütze der Basen.

Sichtweite

Zeigt die Sichtweite der Basen (auch Radar) des Gegners an.
Mit der Dropdownlist kann eine Allianz ausgewählt werden, um die Sichtweite einer Einzelallianz oder aller Gegner-Allianzen anzuzeigen.

Control

none

Im Zoom-Fenster wird die komplette Map nur angezeigt. Es erfolgt keine Änderung der Steuerungsoptionen im Spiel.

game

Für Spieler mit 2 Bildschirmen. Die Maus-Position wird in der Zoommap mit den Koordinaten-Achsen mitgeführt. Die Steuerung erfolgt im Hauptschirm.

zoom

Für Spieler mit 1 oder 2 Bildschirmen. Die komplette Steuerung des Spieles kann über die Zoommap erfolgen. Schiffsgruppen können über eine ‚Bereichsauswahl‘ in der Map ausgewählt werden,
- oder alternativ über folgende Tasten :

  • Pos1 - wählt alle Schiffe
  • 0 - wählt alle Schiffe ab
  • 1 - wählt das mit 1 im Infofenster oben angegebene Schiff.
  • 2 - wählt das mit 2 im Infofenster oben angegebene Schiff.
  • 3 - ...
  • ...

Andere Tasten:

  • s - Synchronisiert AC mit der Position in der Zoommap.
  • PgUp - Alle meine Schiffe blinken.
  • Pos1 - Alle meine Schiffe werden ausgewählt.
  • Ende - Alle ausgewählten Schiffe halten an.
  • p - Screenshot erstellen.

Spezielle Tasten beim Angriff auf fremde Einheiten (im Versuchs-Stadium).
Beim Anklicken einer Fremden Einheit (Angriff) wird durch gleichzeitiges drücken folgender Tasten das Verhalten beeinflusst:

  • shift - NOCH NICHT AKTIV. Zum Snipen. Nach dem Angriffsbefehl wird die angreifende Einheit optimal positioniert.
  • Strg - Ungefähr. Die anzugreifende Einheit muss nicht punktgenau mit der Maus getroffen werden. Es wird die Einheit, im Umkreis von 10 Punkten, attackiert die der Mausposition am nächsten ist.
  • Alt - Verfolgung. Die angegriffene Einheit wird, nach dem ersten Schuss verfolgt. Dafür wird ein Vektor vom Angreifer zur angegriffenen Einheit gebildet und dieser um 3 Punkte verlängert. Die Verfolgung kann abgebrochen werden in dem die verfolgenden Einheiten neu positioniert werden.

Markierungen:

  • m - Setzt eine Markierung an die aktuelle Position.
  • shift + m - Löscht die Markierung wenn sich die Maus genau an der Position des Lesezeichens befindet.

Flugzonen

Zeigt die Flugzonen an, die mit den jeweiligen Schiffstypen durchflogen werden können. Auch Detektorschiffe werden berücksichtigt (Avelabat und Detektor).

Ziele suchen

Für den gewählten Schiffstyp werden mögliche Ziele durch blaue Positionspunkte markiert. Die blauen Punkte markieren dabei die Angriffspositionen, von denen Verlustfrei geschossen werden kann.

Screenshot

So machen Sie einen Screenshot:
• Klicken Sie auf den Screenshot-Button oder drücken Sie die Taste P
• Im Druckdialog wählen Sie "Als PDF speichern" oder "In Google Drive speichern"
• So erhalten Sie eine vollständige Aufnahme des gesamten Fensters inklusive aller Menüs
• Alternativ können Sie das Betriebssystem-Tool verwenden: Win+Shift+S (Windows) oder Cmd+Shift+4 (Mac)

Einheiten suchen

Es können Einheiten für eine Allianz, einen Spieler, einen Schiffstyp oder einer Kombination gesucht werden. Die Listen schränken sich gegenseitig ein, so das Beispielsweise erkennbar ist, welche Spieler den ausgewählten Schiffstyp auf der Map haben.

In der Zoommap werden beim Maus-Over Detail-Informationen in einer Bubble angezeigt und bei einem Maus-Klick in die Infobox übertragen.
